- **[CORRECTNESS]** `certify/certify_pdg.m:309-321` — G3 computes `G3_traj_Linf` but never uses it in `G3_pass`; two solutions can pass G3 with matching mass/time yet materially different position trajectories. Add an explicitly dimensioned trajectory threshold and include it in `G3_pass` (and print it as a scored row).
- **[CORRECTNESS]** `certify/certify_pdg.m:198-199,246-253` — The advertised “report-only and never throws” certification routine throws on time-base assertions. A malformed or failed-solver `solC` therefore prevents a report rather than producing failed gates. Convert these assertions into `rep.G*_pass=false` diagnostics, or revise the interface contract.
- **[CORRECTNESS]** `certify/certify_pdg.m:366-370` — A single interval’s HS defect multiplier is not, in general, the continuous velocity costate at the left node. Node-control stationarity receives contributions from adjacent interval defects, midpoint controls, and active path-constraint multipliers. This primer test can therefore falsely certify or reject PMP alignment. Recover costates using the transcription’s discrete adjoint/KKT mapping, including interval placement and active multipliers, then compare at consistent locations.
- **[CORRECTNESS]** `sim_closed_loop.m:173-180` — Event 3 (mass depletion) is classified as `'arrest'`. Consequently `run_monte_carlo` reports propellant-depletion failures as `n_arrest`, making the campaign’s failure-mode accounting false. Return a distinct `'depleted'` stop value, document it, and add `n_depleted` to the Monte-Carlo report.
- **[CORRECTNESS]** `run_monte_carlo.m:97-102` — Gaussian multiplicative thrust and Isp draws are unbounded. A negative `thrust_scale` reverses the delivered thrust while still consuming propellant; a negative `isp_scale` makes `mdot` positive. Both are nonphysical and can produce invalid “truth” results. Use bounded/truncated or lognormal positive factors, and validate every sampled plant parameter before integration.
- **[CORRECTNESS]** `hs_quad_ctrl.m:69-72,147` — If the vector quadratic crosses zero, `dirT` becomes zero because it is divided by `max(Traw_mag,1e-9)`. The returned thrust is then zero, despite `Tmag` being clamped to the annulus; the documented feasibility guarantee is false. On a near-zero vector interpolant, select a well-defined neighboring/sample direction (or reject the reconstruction), then normalize it to unit length.
- **[CORRECTNESS]** `hs_quad_ctrl.m:105-136` — “Touches a bound” is insufficient evidence that a segment contains a bang-bang discontinuity. A smooth interior/control-cone arc that tangentially reaches a bound is rewritten as a full `Tmin`/`Tmax` step, changing both force history and propellant history. Detect a switch from a certified discrete switching function or require samples on both bound families with a consistent transition; otherwise retain the continuous reconstruction.
- **[ROBUSTNESS]** `solve_pdg_colloc.m:182` — The cold-start final-time guess is `30/Tc`, while the active upper bound is `22/Tc`. IPOPT starts outside a simple scalar bound for every cold solve, unnecessarily invoking restoration and making convergence dependent on solver behavior. Initialize within `[P.tf_lo,P.tf_hi]`, preferably at its midpoint.
- **[ROBUSTNESS]** `pdg_dynamics.m:43,49` — The drag Jacobian divides by `vmag`, and the mass-flow input Jacobian divides by `Tmag`. At exactly zero velocity, the drag force has a well-defined zero Jacobian but this code produces `0/0`; at zero thrust `B(7,:)` also becomes undefined. Add zero/near-zero branches consistent with the limiting derivatives, or use a documented smooth norm consistently in dynamics and Jacobians.
- **[ROBUSTNESS]** `solve_pdg_convex.m:60-85,140-187` — Golden-section search assumes a unimodal, continuously valid objective, but invalid/tightness-rejected probes are represented as `-Inf`. A narrow invalid numerical region can steer the bracket away from the true optimum without any endpoint feasibility check. First map feasible/tight intervals, then optimize only within a contiguous valid bracket; retain all probe diagnostics and explicitly reject a returned point unless `code>=2`.
- **[ROBUSTNESS]** `solve_pdg_convex.m:211-215,265-270` — The implementation calls IPOPT a convex global solver, but IPOPT is a local NLP method and the squared SOC form `sum(Uu.^2) <= S.^2` is not supplied as a cone to a conic solver. The mathematical feasible set is convex for `S>=0`, but globality is not established by this implementation. Use a conic-capable backend/formulation for the certification solver, or remove the global-optimum claim and independently verify KKT/primal residuals.
- **[ROBUSTNESS]** `tvlqr_design.m:320-321,326-337` — `tBlend` and `R` are not validated. `tBlend=0` creates division by zero in `tanh`; an indefinite/singular `R` makes `inv(R)` invalid and invalidates the Riccati problem. Require finite `tBlend>0` and symmetric positive-definite `R`; replace `inv(opts.R)` with a factorization/linear solve.
- **[ROBUSTNESS]** `run_monte_carlo.m:55-83` — `Nrun`, dispersion values, and `P.seed` are not validated for finite, nonnegative, integer-appropriate values. In addition, `rng(P.seed)` mutates the caller’s global random stream. Validate inputs and save/restore RNG state (or use an isolated random stream) so campaign determinism does not silently perturb unrelated simulations.
- **[STYLE]** `certify/certify_pdg.m:228-238` — `G1_defect=max(abs(d))` takes a maximum over metres, m/s, and kg and compares the dimensionally mixed scalar to `1e-6`. Although conservative numerically, it is not a physically meaningful norm. Report per-state-row SI residuals or a nondimensional residual norm with separately stated SI acceptance limits.
- **[STYLE]** `tvlqr_design.m:350-353` — The switch detector is explicitly known to be wrong for a multi-switch profile, yet the code permits drag and cone configurations that can change throttle structure. Make the scheduling logic reject unsupported structures or derive phase scheduling from all detected arcs rather than silently applying a two-phase controller.

Overall, the core HS scaling, free-time chain rule, convex-variable unscaling, Riccati time reversal, airspeed/ground-speed handling, and vertical-priority allocation are largely sound. The largest assurance gaps are not basic dynamics algebra but certification integrity: G3 omits its trajectory metric, G5 treats raw defect duals as costates without the discrete-adjoint mapping, and event/Monte-Carlo bookkeeping can misstate failure causes.
